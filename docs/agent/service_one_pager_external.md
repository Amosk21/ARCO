## Proof of capability

**ARCO** (AI Risk Classification Ontology) is a working OWL-RL classification pipeline built over a BFO-aligned class hierarchy for EU AI Act Annex III risk classification.

It classifies AI systems via formal entailment — not keyword matching or hardcoded rules. The gate logic (capability type, intended use, use scenario) is independently tested through gate-removal regression and adversarial test cases. Classification, documentary validation, and audit run as separate layers.

ARCO currently implements Annex III categories 1(a) (biometric identification) and 5(b) (creditworthiness evaluation).

Background in applied ontology developed through NCOR-connected coursework and collaboration.
